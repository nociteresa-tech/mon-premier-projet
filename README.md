# 💧 AquaTrack

> Système de surveillance en temps réel de la qualité de l'eau à faible coût

---

## 📌 Description

AquaTrack est un système embarqué low-cost permettant de surveiller 
en temps réel la qualité de l'eau potable dans les quartiers de Yaoundé, 
Cameroun. Il combine des capteurs physiques et une interface mobile 
pour alerter les populations en cas de contamination.

---

## 🚨 Problème résolu

À Yaoundé, l'accès à une eau de qualité contrôlée reste limité.
Les analyses laboratoires sont coûteuses et non accessibles en temps réel.
AquaTrack propose une solution autonome, connectée et abordable.

---

## ⚙️ Fonctionnalités

- 📊 Mesure en temps réel : pH, turbidité, température, conductivité
- 📱 Interface mobile d'affichage et d'alertes
- 🔔 Notifications en cas de dépassement de seuils
- 💾 Historique des données de qualité

---

## 🛠️ Technologies utilisées

| Composant     | Technologie                  |
|---------------|------------------------------|
| Capteurs      | Arduino + capteurs pH/turbidité |
| Communication | Module WiFi ESP8266          |
| Interface     | HTML / CSS / JavaScript      |
| Versioning    | Git / GitHub                 |
